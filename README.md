# mobilka132

Android-приложение для навигации по Томску и демонстрации алгоритмов оптимизации, поиска и машинного обучения.

Приложение объединяет интерактивную карту, построение пешеходных маршрутов, планирование посещения заведений, решение задачи коммивояжёра, кластеризацию, симуляцию студентов и распознавание рукописных цифр.

## Возможности

- интерактивная карта с масштабированием и перемещением;
- выбор точек на карте с привязкой к ближайшей доступной области;
- построение маршрута между двумя точками;
- пошаговая визуализация алгоритма A*;
- добавление и редактирование линейных препятствий;
- отображение информации о зданиях, заведениях, меню и часах работы;
- поиск зданий и заведений;
- определение текущего местоположения через GPS;
- русский, английский и китайский языки интерфейса;
- светлая, тёмная и пользовательская цветовая тема.

## Реализованные алгоритмы

### A*

Пешеходный маршрут строится по растровой карте с использованием 8 соседних направлений. Вес клетки зависит от проходимости карты, а диагональные и ортогональные переходы имеют разные стоимости. Алгоритм поддерживает пошаговую визуализацию открытого и закрытого множеств.

### Генетический алгоритм

Используется для планирования маршрута по выбранным заведениям и сбора требуемых блюд. При оценке маршрута учитываются:

- расстояния по проходимой карте;
- часы работы заведений;
- время посещения;
- наборы блюд;
- недоступность отдельных участков;
- начальная позиция пользователя.

В реализации используются мутации маршрута, удаление и добавление точек, инверсия участков и локальная оптимизация 2-opt. По умолчанию выполняется 200 поколений.

### Муравьиный алгоритм / TSP

Алгоритм ищет маршрут через выбранные здания. Расстояния предварительно вычисляются через A* и кэшируются. Используются феромоны, испарение феромонов, эвристика обратного расстояния и случайный выбор следующей точки.

### K-means и K-medoids

В проекте есть обычный K-means++ для точек и бонусная реализация K-medoids. Бонусный режим сравнивает кластеризацию по трём метрикам:

- евклидово расстояние;
- манхэттенское расстояние;
- расстояние по пешеходному пути A*.

Количество кластеров можно выбрать от 2 до 8. В режиме различий отображаются точки, для которых метрики дали разные кластеры.

### Симуляция кампуса

Модель студентов-муравьёв ищет свободные коворкинги на растровой карте. Муравьи оставляют феромоны по направлениям к коворкингам и обратно к стартовой точке. Вместимость и комфорт коворкингов берутся из данных зданий.

### Дерево решений

Модуль подбора заведения строит дерево решений по `restaurants.csv`. Для выбора признака используется прирост информации, затем дерево оптимизируется и ограничивается глубиной 3.

Пользователь может:

- отвечать на вопросы дерева;
- указать бюджет;
- просмотреть путь принятия решения;
- изменить обучающую CSV-выборку;
- визуализировать структуру дерева.

### Распознавание цифр

В приложении есть экран тестирования и диалог оценки заведения. Пользователь рисует цифру, после чего изображение проходит обработку:

1. обрезка по ограничивающему прямоугольнику;
2. бинаризация методом Отсу;
3. скелетизация;
4. дилатация;
5. масштабирование и центрирование в изображение 28×28;
6. размытие Гаусса;
7. классификация нейронной сетью.

Используемая в Android сеть по сохранённым весам имеет архитектуру `784 → 64 → 32 → 10` с ReLU на скрытых слоях и softmax на выходе.

## Сборка и запуск

Откройте проект в Android Studio с установленным Android SDK 35 или выполните из корня проекта:

### Linux/macOS

```bash
./gradlew assembleDebug
```

### Windows

```bat
gradlew.bat assembleDebug
```

APK обычно появляется в каталоге:

```text
app/build/outputs/apk/debug/app-debug.apk
```

Запуск тестов:

```bash
./gradlew test
./gradlew connectedAndroidTest
```

Для работы GPS необходимо выдать приложению разрешение на доступ к местоположению и включить службы геолокации на устройстве.

## Данные и ресурсы

- `app/src/main/assets/map750.png` — карта проходимости для алгоритмов;
- `app/src/main/res/drawable/perfect_colored_map750.png` — цветовая маска зданий;
- `app/src/main/res/drawable/user_map_contrast.png` — визуальный слой карты;
- `app/src/main/assets/ga_points.csv` — точки для генетического алгоритма;
- `app/src/main/assets/restaurants.csv` — обучающая выборка дерева решений;
- `app/src/main/assets/tsp.csv` — набор точек TSP;
- `app/src/main/assets/weights/` — веса Android-модели распознавания цифр;
- `digit_recognition_python/` — Python-скрипты подготовки данных и обучения модели;
- `ga_bonus/` — отдельный бонусный генетический алгоритм генерации программы на C.

## Обучение модели цифр

Каталог `digit_recognition_python` содержит самостоятельный Python-пайплайн на NumPy:

- подготовка MNIST и пользовательских изображений;
- обучение сети с ReLU и softmax;
- экспорт весов в CSV;
- создание пользовательского набора из папок с цифрами.

Перед обучением требуются Python-зависимости из используемых импортов (`numpy` и, для пользовательских изображений, `Pillow`). Обучающий CSV MNIST намеренно не хранится в репозитории из-за размера.

> Важно: текущие параметры сети в `digit_recognition_python/main.py` (`784 → 256 → 128 → 10`) отличаются от размерностей весов, поставляемых в Android (`784 → 64 → 32 → 10`). При переобучении необходимо привести архитектуру и экспортируемые веса к одной размерности.
